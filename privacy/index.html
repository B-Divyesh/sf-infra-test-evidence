Product policy

Privacy

Infra Test Evidence has no analytics, accounts, cookies, or upload feature.

Browser reader

The browser reads your selected evidence file in memory. The site does not send its contents anywhere.

Command-line tool

Conversion mode reads the file you name. It writes only to standard output and the paths passed to --junit and --evidence-dir.

The --demo flow creates one new directory under your operating system's temporary directory. It prints that directory when complete.
