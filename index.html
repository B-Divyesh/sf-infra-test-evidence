Three local steps

How it works

  1. Capture the run.Save OpenTofu or Terraform test -json output.
  2. Convert the evidence.Create JUnit, reviewer JSON, and a static HTML page.
  3. Review the result.Open the redacted page from disk or inspect a compact record above.

Small by design

CI outputs and record format

Run the converter against tofu test -json or terraform test -json output to create a JUnit report and a self-contained reviewer page. The page includes test inputs, assertion paths, redacted plan changes, failures, and provenance.

infra-test-evidence --junit report.xml --evidence-dir evidence tofu-test.jsonl

The local reader also accepts the compact portable record used by earlier workflows:

{
  "run": "staging-2026-08-27.1",
  "environment": "staging",
  "recordedAt": "2026-08-27T12:00:00Z",
  "checks": [{ "name": "HTTP health", "status": "pass" }]
}

Use infra-test-evidence --json evidence.json to strictly validate this compact form in CI.

Boundaries

What it does not do

It does not upload files, run infrastructure changes, or replace a reviewer. It only converts and displays the evidence you provide.
